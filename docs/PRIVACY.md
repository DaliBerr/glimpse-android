# 拾光隐私说明

拾光（Glimpse）是由 [DaliBerr](https://github.com/DaliBerr) 维护的本地相册整理应用。数据处理相关问题可通过[项目反馈入口](https://github.com/DaliBerr/glimpse-android/issues)提出，请勿在公开反馈中上传私人照片。

## 照片与整理记录

- 照片通过安卓系统 MediaStore 读取，显示文件名、相册、文件大小、像素尺寸和拍摄时间；需要时补读 EXIF。
- 照片、照片信息和整理记录不会上传到开发者服务器或更新服务。
- 保留、待删除等记录保存在私有 SQLite 数据库，外观设置保存在本机。关闭应用后继续保留。
- 应用无账号、广告或分析统计 SDK，并关闭系统云备份及设备迁移的数据提取。
- 清除应用数据或卸载应用会清除私有整理记录；这与正式删除原图是不同的操作。

## 分享与删除

分享由用户主动发起，系统将所选照片的临时读取权限交给用户选择的应用。目标应用如何处理照片，取决于其自身的隐私政策。

加入待删除清单不会修改原图。正式删除由用户确认并经系统授权执行，完成后应用不提供原图恢复。

## 检查更新时的联网

检查和下载更新由用户主动触发。应用请求 GitHub 的公开版本、更新清单及安装包，不携带照片、照片信息、整理记录或账号令牌。

GitHub 及其下载服务会接收到普通网络连接所需的 IP 地址和请求信息，相关处理适用 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。应用使用 HTTPS，安装包下载到私有缓存，安装前检查哈希值、包名、版本与签名。

缓存可能被系统清理，应用启动时会重新校验。安装需要用户操作和安卓系统确认，不会静默执行。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| 照片读取 | 整理用户授权的本机照片 |
| 部分照片访问 | Android 14 及以上只整理用户选定的照片 |
| 网络访问 | 用户主动检查版本和下载更新 |
| 请求安装应用 | 用户主动安装校验通过的拾光更新包 |

用户可随时在安卓系统设置中调整照片和安装来源权限。
